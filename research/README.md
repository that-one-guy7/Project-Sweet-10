# Research notebook

Use this directory for public-source notes, exact upstream revisions, and reproducible observations. Every note should identify the source URL, commit SHA or release, date checked, and whether the statement is upstream fact, local observation, or hypothesis.

Do not store firmware images, proprietary iOS binaries, full device dumps, credentials, serial numbers, ECIDs, IMEIs, or calibration data here.

Start with [the source matrix](source-matrix.md), [reference revisions](REFERENCE_REVISIONS.md), and [the 20H392 reference record](20H392-reference.json).
